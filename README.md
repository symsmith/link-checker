# link-checker

Find broken links in Markdown files. A project to learn Effect v4.

## Scripts

| Command             | What it does                               |
| ------------------- | ------------------------------------------ |
| `pnpm start`        | Run `src/main.ts` with Node (no build)     |
| `pnpm check`        | Type-check with TypeScript 7               |
| `pnpm lint`         | Lint with oxlint (type-aware + type-check) |
| `pnpm lint:fix`     | Lint and auto-fix                          |
| `pnpm format`       | Format with oxfmt (sorts imports, JSDoc)   |
| `pnpm format:check` | Check formatting only                      |
| `pnpm test`         | Run tests once with Vitest                 |
| `pnpm verify`       | All of the above checks                    |
